## Features

Apex currently includes the following source-verified areas of functionality:

- **Moderation & management:** moderation actions, role management, purge/cleanup tools, server management, permissions, blacklist/ignore controls, and administrative utilities.
- **Security:** Antinuke, AntiBetray, AutoMod, security/event logging, and related whitelist/configuration controls.
- **Automation & onboarding:** JoinRole/AutoRole, reaction roles, vanity roles, AutoReact, Welcome/Farewell, Join2Create, AutoBump, Autopost, and scheduled reminders.
- **Community systems:** tickets, giveaways, feedback tools, todos, counting, user/server/bot profiles, and server statistics/information.
- **Tracking:** invite tracking and message-count tracking, plus related server/member utilities.
- **Search & information:** Google, YouTube, GitHub, Wikipedia, news, cryptocurrency, conversion, animal, and other information commands.
- **AI & media:** AI chat, image generation, text-to-speech, media utilities, and an image-analysis command in the source tree. Some AI functions are premium-gated.
- **Command interfaces:** slash commands, prefix commands, hybrid commands, and no-prefix support.

Features may change, be removed, or be added at any time.

## Server Security

Apex operates within Discord's permission system and API limitations. It cannot override Discord permissions or role hierarchy.

If another member's highest role is above Apex's highest role, Apex may be unable to moderate or manage that member. Features that perform moderation, role changes, channel management, logging, or other administrative actions also require the permissions needed for those actions.

Server owners and administrators are responsible for configuring Apex correctly and for configuring their Discord server safely. Security features are defensive tools and are **not a guarantee** against raids, nukes, compromised accounts, permission abuse, malicious actions, or other security incidents.
